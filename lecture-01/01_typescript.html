პირველი ნაბიჯები TypeScript-ში

რა არის TypeScript?

TypeScript არის JavaScript-ის გაფართოება, რომელიც ამატებს ტიპებს (types).

JavaScript + ტიპები = TypeScript

TypeScript კოდი კომპილირდება JavaScript-ში — მუშაობს ნებისმიერ ბრაუზერსა და Node.js-ზე.

მთავარი უპირატესობები

  • 🛡 შეცდომების გამოვლენა — წერის დროს, გაშვებამდე
  • 💡 უკეთესი IDE — ავტოშევსება, IntelliSense
  • 📖 თვითდოკუმენტირება — ტიპები ხსნის კოდს

ფუნქციები — ცხოვრებისეული მაგალითები

// ფასი + გადასახადი
function calcTotal(
  price: number, tax: number
): number {
  return price + price * tax;
}

// ასაკის შემოწმება
function canVote(age: number): boolean {
  return age >= 18;
}

// მისალმება
function welcome(name: string): string {
  return `კეთილი იყოს, ${name}!`;
}

console.log(calcTotal(100, 0.18));
console.log(canVote(20));
console.log(welcome("ნინო"));

useState + კლიკი — მაგალითები

import { useState } from "react";

// კალათა
function Cart(): JSX.Element {
  const [items, setItems] = useState(0);
  return (
    <div>
      <p>კალათაში: {items} ც.</p>
      <button onClick={() =>
        setItems(items + 1)}>+</button>
      <button onClick={() =>
        setItems(items - 1)}>-</button>
    </div>
  );
}

// ლაიქები
function LikeBtn(): JSX.Element {
  const [likes, setLikes] = useState(0);
  return (
    <button onClick={() =>
      setLikes(likes + 1)}>
      ❤️ {likes}
    </button>
  );
}
