# ლექცია 03: Arrays — საკლასო სამუშაო

## მიზანი

მასივების მეთოდების, spread/rest ოპერატორებისა და Tuple-ების პრაქტიკა.

## ამოცანა 1: map / filter

```ts
const numbers = [5, 12, 8, 130, 44];

// 1.1. გააკეთეთ ახალი მასივი თითოეული ელემენტის გაორმაგებით (map)
// 1.2. გაფილტრეთ მხოლოდ 10-ზე მეტი რიცხვები (filter)
// 1.3. გაფილტრეთ და შემდეგ გააორმაგეთ (chain)
// 1.4. გადააქციეთ რიცხვები სტრიქონებად: "რიცხვი: X"
```

## ამოცანა 2: reduce

```ts
const prices = [45.99, 12.50, 99.99, 8.00, 250.00];

// 2.1. გამოთვალეთ ჯამი (reduce)
// 2.2. გამოთვალეთ საშუალო
// 2.3. იპოვეთ მაქსიმალური ფასი
// 2.4. გააკეთეთ სტრიქონი: "ფასები: 45.99, 12.50, ..."
```

## ამოცანა 3: some / every / includes / find

```ts
const words = ["TypeScript", "JavaScript", "Python", "Java", "C++"];

// 3.1. არის თუ არა ერთი მაინც სიტყვა 10 სიმბოლოზე მეტი? (some)
// 3.2. ყველა სიტყვაა თუ არა 2 სიმბოლოზე მეტი? (every)
// 3.3. მოიცავს თუ არა "Python"-ს? (includes)
// 3.4. იპოვეთ პირველი სიტყვა, რომელიც იწყება "J"-თი (find)
```

## ამოცანა 4: Spread / Rest

```ts
const groupA = ["მარიამი", "გიორგი", "ნინო"];
const groupB = ["დავითი", "ანა", "ლევანი"];

// 4.1. გააერთიანეთ ორივე ჯგუფი spread-ით
// 4.2. დაამატეთ "თამარი" მეორე პოზიციაზე
// 4.3. დაწერეთ ფუნქცია, რომელიც იღებს rest-ით სახელებს
//      და აბრუნებს მათ სიას ნუმერაციით
```

## ამოცანა 5: Destructuring

```ts
// 5.1. დესტრუქტურიზაცია მასივიდან
const point = [15, 25, 35];
// გამოიტანეთ x, y, z

// 5.2. Rest-თან ერთად
const rgb = [255, 128, 64, 0.5];
// პირველი სამი — ფერი, ბოლო — გამჭვირვალობა

// 5.3. Tuple-ის დესტრუქტურიზაცია
const product: [string, number, string] = ["ლეპტოპი", 2500, "მარაგშია"];
```

## ამოცანა 6: 2D მასივი (მატრიცა)

```ts
const matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9],
];

// 6.1. დაბეჭდეთ მთავარი დიაგონალი (1, 5, 9)
// 6.2. გამოთვალეთ ყველა ელემენტის ჯამი
// 6.3. გადააქციეთ 1D მასივად (flat)
// 6.4. გააკეთეთ ტრანსპონირება (სტრიქონები <-> სვეტები)
```
