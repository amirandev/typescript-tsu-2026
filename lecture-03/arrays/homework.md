# ლექცია 03: Arrays — საშინაო დავალება

## ამოცანა: Data Processing Pipeline

შექმენით მონაცემთა დამუშავების პროგრამა TypeScript-ში, რომელიც მუშაობს მასივებთან.

### 1. მონაცემები

`	s
const salesData = [
  { product: "ლეპტოპი", amount: 1500, quantity: 3, category: "ელექტრონიკა" },
  { product: "წიგნი", amount: 25, quantity: 10, category: "განათლება" },
  { product: "ტელეფონი", amount: 800, quantity: 5, category: "ელექტრონიკა" },
  { product: "კალამი", amount: 2, quantity: 100, category: "საკანცელარიო" },
  { product: "პლანშეტი", amount: 600, quantity: 2, category: "ელექტრონიკა" },
  { product: "რვეული", amount: 3, quantity: 50, category: "საკანცელარიო" },
];
`

### 3. reduce

`	s
// 3.1. გამოთვალეთ მთლიანი შემოსავალი (ყველა amount * quantity)
