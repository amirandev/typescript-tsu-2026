# ლექცია 02: საკლასო სამუშაო

## მიზანი

სხვადასხვა ტიპის ცვლადების გამოცხადების პრაქტიკა.

## ამოცანა 1: ცვლადების გამოცხადება

დაწერეთ TypeScript კოდი, სადაც გამოაცხადებთ:

```ts
// 1. string ცვლადი — თქვენი სახელი
// 2. number ცვლადი — თქვენი ასაკი
// 3. boolean ცვლადი — ხართ თუ არა სტუდენტი
// 4. string[] ცვლადი — თქვენი ჰობიების სია
// 5. null ცვლადი — ცარიელი მნიშვნელობა
```

## ამოცანა 2: Type Inference

შეამოწმეთ ტიპის გამოცნობა:

```ts
// გამოაცხადეთ ცვლადები მნიშვნელობებით, ტიპის მითითების გარეშე
let city = "თბილისი";
let population = 1100000;
let isCapital = true;

// სცადეთ მიანიჭოთ სხვა ტიპის მნიშვნელობა
// city = 42; // გამოიწვევს თუ არა შეცდომას? რატომ?
```

## ამოცანა 3: unknown-ის გამოყენება

```ts
function processData(data: unknown): void {
  // 1. შეამოწმეთ data-ს ტიპი
  // 2. თუ string-ია — დაბეჭდეთ სიგრძე
  // 3. თუ number-ია — გაამრავლეთ 2-ზე
  // 4. თუ boolean-ია — დაბეჭდეთ შებრუნებული
}

processData("Hello");
processData(42);
processData(true);
```

## ამოცანა 4: Union ტიპები

```ts
// გამოაცხადეთ ID, რომელიც შეიძლება იყოს string ან number
let userId: string | number;

userId = "abc123"; // OK
userId = 123;      // OK
// userId = true;  // ❌ — boolean არ შედის Union-ში
```
